# Portfolio Design Mockup: Stitch

Este directorio contiene las referencias visuales y maquetas del diseño "Stitch" para el portfolio.

## Contenido

- `mockup_stitch.html`: Maqueta base en HTML/CSS que define la estética del sitio.

## Instrucciones

Este diseño debe ser la referencia principal para la creación de componentes en Astro. Al ser un proyecto de código abierto, mantenemos esta referencia aquí para que cualquier colaborador pueda entender la dirección visual del proyecto.
